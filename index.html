Input Data Imunisasi

Masukkan capaian imunisasi per desa untuk periode yang dipilih. Data otomatis tersimpan ke Firebase Cloud.

Data tersimpan langsung di Firebase Firestore Cloud secara gratis & realtime.

Isi jumlah capaian untuk masing-masing vaksin dan jenis kelamin. Sasaran 0-50.

Pastikan input **Periode** (Bulan/Tahun) sudah terisi sebelum klik Simpan.

Form BIAS (Pendataan Sekolah Multi-Kelas)

Pilih nama sekolah. Gunakan tombol **Tambah Input Kelas** untuk memasukkan data setiap kelas yang dilaporkan.

Data BIAS tersimpan secara terpusat di cloud.

Input Data Kelas (Sasaran & Capaian)

Pilih sekolah di samping kiri untuk mengaktifkan input kelas.

Export Data

Panel cepat untuk mencadangkan database atau menarik data dari Cloud.

Backup JSON Cloud

Unduh seluruh snapshot laporan dari cloud dalam format **.json** sebagai cadangan offline.

Import Data ke Cloud

Pilih file database **(.json)** untuk menyinkronkan data secara masal ke Firebase Cloud Firestore.

Hasil Kumulatif Imunisasi dan BIAS (Realtime Cloud)

Menampilkan total capaian dan rincian per bulan dari seluruh laporan yang tersimpan di Firebase Firestore.
